# Kite Plus Identity

The shared sign-in for every Kite Plus service, served at `id.kite.plus`.

It is a self-hosted open-source identity provider (OIDC), deployed unmodified. This repository holds only what it takes to run it: deployment files, repeatable setup scripts, backups, runbooks, branding and email templates.

This repository is in the planning stage. There is no deployment yet. The design, written in Chinese like the other Kite Plus projects, is in [docs/design](docs/design/README.md). Start with [architecture.md](docs/design/architecture.md) and the milestones in [roadmap.md](docs/design/roadmap.md).
